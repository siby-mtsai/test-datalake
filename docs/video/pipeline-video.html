The infrastructure

Everything runs in the Test AWS account and is built by Terraform (terraform/envs/test).
• EventBridge Scheduler starts jobs on a timer
• ECS Fargate runs our Go code in containers
• RDS Postgres is the source database
• Secrets Manager holds its password
• S3 stores every lake file
• Glue knows where each table lives
• Athena runs SQL over the files
• CloudWatch + SNS log everything and email on failure

07:00 UTC: the schedule fires

terraform/modules/export-task
schedule_expression = "cron(0 7 * * ? *)" # 07:00 UTC = 12:30 IST launch_type = "FARGATE" task_definition = "…-export"
No server is running beforehand. Fargate starts a fresh container just for this run and stops it when the job finishes.

Step 5: commit into Iceberg

lake.CommitToIceberg()
export/internal/lake/iceberg.go · four SQL statements via Athena
5a CREATE EXTERNAL TABLE …_staging_6f1c… LOCATION 's3://…/raw/_staging/…/6f1c…/' 5b DELETE FROM trip_events WHERE event_date = DATE '2026-07-07' 5c INSERT INTO trip_events SELECT * FROM …_staging_6f1c… 5d DROP TABLE …_staging_6f1c…
Athena does the real work: it writes new Iceberg data + metadata files, then Glue's pointer moves to the new version. That pointer move is the commit.

Weekly and daily housekeeping

cmd/compact, Sunday 03:00 UTC
VACUUM trip_events · VACUUM trip_events_curated
Removes old versions and deletes files nothing uses anymore.
cmd/trim
Drops old Postgres day-partitions, but only if that day's manifest exists and says success:true. The lake copy is proven before the source copy is removed.
cmd/erasure
Deletes one vehicle's rows from both tables, then VACUUMs, so no old version can bring them back.
